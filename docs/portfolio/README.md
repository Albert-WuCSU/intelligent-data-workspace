# 公开展示包

此目录只包含通用自编架构/封面、已目检的自有合成联调截图、独立合成Demo截图和经过白名单过滤的项目进度快照。页面不请求API、不读取本机账本、无密钥或访客数据。

`progress.html` 可单文件下载离线打开；`../demo/index.html` 与对应CSS/JS一起提供独立引導演示。GitHub源码页不执行HTML；在线访问需要静态托管。

荧光限于已验收的本机模块范围；绿色步骤按实现/测试/来源hash证据产生，新的QF步骤仍pending。展示不是生产认证、真实业务数据或用户验收。生成脚本与本机完整实现可能未在该次发布范围内；发布快照版本见export-manifest.json。
