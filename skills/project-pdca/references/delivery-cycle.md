# 模块交付循环与门禁

## PLAN 最小交付

每模块一份 plan.md，包含目标与非目标、输入输出/API/资产Schema、已批准技术栈与本模块差异、依赖、垂直切片、需求ID及验收条件、测试矩阵、风险、回滚与用户decision_id。验收条件描述可观察行为，不是“实现某功能”。初步工作量说明依赖、假设和不确定性，不承诺无法验证的日期。

每模块在PLAN加入用户任务卡：主要角色与情境、核心问题、最短默认路径、非目标、必须披露的口径/风险、可观察的任务成功条件、尚待验证假设。既有项目用户原则优先读取；具体要求见product-user-thinking.md。

关键选择发生在：立项范围与部署；首次共享栈及各模块新依赖；真实数据和身份权限；重要指标口径/统计识别方法；破坏性接口或迁移；付费资源；正式交付；生产部署。技术栈已经批准后低风险库内实现不重复问。用户说“推荐方案”时对应当前唯一显示选择，不能把模糊赞同当作全部未来批准。

## DO 实现切片

把一个切片写成需求→代码→测试→演示的闭环。保存受影响文件、启动命令、配置示例与环境依赖；.env.example只含变量名及非敏感示例。接口变更检查上下游消费者和迁移兼容。现有代码、用户未提交变更先盘点，不覆盖或清理。

## CHECK 测试矩阵

| 类型 | 使用时机 | 必测内容 |
| --- | --- | --- |
| 单元 | 每个有逻辑的模块 | 正常、边界、异常及幂等 |
| 契约 | API/MCP/资产或模块边界 | Schema、类型、权限上下文、版本不兼容 |
| 集成 | 两个真实组件对接 | 真实响应、超时、取消、重试与失败分类 |
| 端到端 | 可交付用户流程 | 从身份及输入到结果、权限与追溯 |
| 安全 | 身份、数据、插件或执行 | 跨租户、行列限制、注入、密钥及外传 |
| UI | 用户可见界面 | 真实交互、加载/失败/空态、字段单位、视觉检查 |
| 数据方法 | 归因、建模、实验 | 金标准、基线、粒度、泄漏、守恒或识别假设 |
| 运维 | 异步执行与交付 | 恢复、取消、资源清理、限额和可复现运行 |

依据风险选择深度；纯逻辑库无UI无需做UI检查。测试证据标记 passed/failed/not_run 及mock/real/local/staging环境，保存命令、退出码、必要输出、代码指纹和时间。必要真实集成缺失时不能把mock替代成passed。代码或配置变更后，受影响旧证据置stale并重跑；与新变更无关的旧证据可复用但要说明依据。

## ACT 审计清单

1. 范围：需求到实现及测试的映射，缺项与约定排除项明确。
2. 证据：已执行、可复现、针对当前代码；测试环境和限制准确。
3. 安全：身份、资源、输出、下载及日志无权限提升或秘密泄漏。
4. 契约：Schema与版本符合计划；上下游集成未回归。
5. 错误：权限、不支持、超时、空结果、敏感数据、部分成功行为符合规定。
6. 运维：运行说明、配置、取消/恢复、资源边界与回滚可用。
7. 交付：结果路径、剩余事项、风险等级、环境成熟度和用户验收记录。
8. 产品可用性：核心入口可发现、无需无关技术操作、状态真实、输出可理解、证据渐进披露、下一步可执行。记录走查范围和缺少的真实用户验证，不用技术测试替代。

每模块最终一份audit.md即可，记录 reviewer=self_review 或真实独立审计者。检查失败记录fail及整改，不用“基本完成”代替状态。critical/high级未解决问题阻止audit pass。medium/low可经明确风险接受保留。production_verified必须有真实目标环境证据；local_ready只是本地范围交付。

## 返工和下一模块

失败时按同一方案DO修复；根本方案变化回PLAN。记录cycle_id和change_impact，保留旧证据历史。module closed需plan approval、当前验收证据、audit pass及delivery approval。下一模块的硬依赖必须closed；依赖被用户显式取消/移出范围时先重新审核下游计划，不能用skip假装实现了依赖。

项目阶段发布另设门禁：模块完成不能自动代表整个MVP、真实数仓集成或生产就绪。真实验证延期事项、迁移、安全与端到端验证进入release_gates；未满足前不得宣称可生产上线。

## PRD及模型切片重排的门禁

用户要求模块PRD时独立维护需求/来源/AC行为/未验证边界，核对模块索引和依赖与progress一致；详细plan和delivery仍逐模块确认。若本项目批准模型服务前置，则按ROADMAP/M04-A及原M04=M04-B引用，现有阻断选择保留。新模型供应商、LangGraph等版本/许可/安装、付费/数据外发及checkpointer持久化分别核验；PRD写完不能让模型调用或Agent集成测试变passed。
