# 通用数据Agent规划约束
仅适用于universal-data-agent；D-ARCHITECTURE-GENERALIZATION-080，规划/自审/续接时结合project-control/ARCHITECTURE_V2.md读取。这里只含行业无关范式，不引用机密材料。

- 保持D070 SDK/Skills/Harness及已有验收模块，模型动态选择能力，确定性代码约束危险执行与输出，不因参考图改回全推理硬编码图引擎。
- 请求先明确任务/指标候选/修饰/时间/分组筛选排序/比较/未决槽位；模型提意图，批准目录、日历/时区、枚举和字段合同负责落地。公开常识不覆盖内部业务默认值，关键歧义同任务澄清。
- L1-L4先检查适用性，明确目标可跳过不适用能力但不得跳授权/确认/预算；RouteDecision记录理由/版本。权限拒绝停，UNKNOWN只读查回执不重提，QA失败不换路线冒充成功。仅可证明不会重复执行的可恢复步骤才有限重试，旧预算不reset。
- 复杂请求按必要依赖拆TaskPlan；比较/比例/多输出的单位、粒度、分母与覆盖要验证，单次聚合可解不拆。并行/子Agent/新执行能力需实际授权，此参考不授权委派。
- 工具CapabilityManifest与Skill目录分开；Skill先description召回再按需正文，版本/审核状态/权限与route token在后端落实。生成/实验Skill待审核，不自动执行；审核级别不与查询路由层级同名。
- 任务状态、短期上下文、长期用户偏好、业务知识、数据资产/缓存分开。偏好只显式存，不能定义业务口径/权限；ContextEnvelope有owner/source/model/semantic版本、用途/同意/限额，不默认发送全历史/结果行。长期持久化/保留属于M05门禁。
- 输出来源、执行、QA、业务审核和方法证据分轴；绿色或标准路径不是质量认证，统计贡献不是因果；失败/空/partial/unknown有行动建议，数字必须可溯回执，参考材料百分比/效果不作证据。
- 先合成合同和金标准，再受控集成与用户验收；新模型/分类器/向量库/服务/费用/公司数据/沙箱要单独核验批准，不照搬多数据库或框架堆栈。
- 机密原图/PDF/逐页摘要/公司字段案例/内部系统/水印不得写公开项目/规划Skill/fixture或调用模型。衍生泛化不自动获得公开IP许可；公开推送前确认允许范围。只更新本项目Skill及对应安装副本，不改其他Skill。
