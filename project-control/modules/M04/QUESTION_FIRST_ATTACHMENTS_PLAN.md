# 自然语言优先、Agent选源与任务附件规划
2026-11-06 · D-M04-QUESTION-FIRST-UX-086 · design_only / implementation not_run

## 1. 用户任务与默认路径
业务用户直接描述问题，不需要知道标准口径、指标ID、表名或数据源。输入区只保留自然语言、可选任务附件、已测试模型选择及必要外发/费用同意。**删除默认工作台“问数口径”选择控件和右栏“来源与附件”勾选列表**，不能只是移到另一个必填弹窗。右栏保留真实任务摘要、已使用来源、输入附件、产物与证据的只读展示，不是全量候选源目录。接入、授权、语义发布继续在管理员页面；删除业务控件不删除已保存数据/连接。

最短路径：问题＋可选附件→判断取数/指标或知识咨询/分析/归因等意图→选择适用能力→探索授权语义、知识和元数据→关键歧义才用业务语言确认→Agent建议并绑定有权限的来源/字段/口径→必要执行确认→真实执行/QA/回执→正文及结果证据。
用户可以明确指定来源或提供表名，但这是可选约束，不是普通任务前置。Agent选源只在服务端授权集合内，不自行获取凭证/扩展权限。多来源或隐私用途有重大差异时再向用户解释选择和后果，而非让业务用户辨认数据库。

## 2. L1–L4与任务分流
保持ARCHITECTURE_V2现有编号含义：L1已发布标准指标、L2已审核主题查询能力、L3授权元数据与受控查询、L4授权知识/口径咨询与检索。先查适用性，不机械跑完四层；L4知识证据可辅助其他路线澄清，但不是SQL执行的兜底或权限旁路。查到候选口径后展示定义、期间/粒度/单位/过滤和证据，关键含糊点与用户确认；没有证据就问，不把模型常识发布为企业标准。
“列出指标/解释口径，暂不取数”属于发现/咨询任务，合法终态是带来源的说明或空结果，不要求SQL/QueryReceipt，否则就会把未取数误判为查询发布失败。仍需自身发现/知识回执与owner/版本检查，不能伪造QueryReceipt。用户反馈截图显示SDK_PUBLICATION_MISSING，此处仅记录用户报告的失败，未读运行日志、未确证根因/当前服务版本，不重试收费任务。
分析/归因请求先查方法与能力适用性：已批准分析能力才执行；未实现则明确限制并澄清目标，必要数据准备单独说明/确认，不将所有请求硬塞成取数。贡献/相关性不等于因果；M09等后续能力、沙箱和生产门禁不前置为已实现。

## 3. RAG未实现时先适配的合同
规划KnowledgeQuery / KnowledgeEvidence / KnowledgeLookupReceipt与统一KnowledgeProvider端口（名称待实现冻结）：绑定owner/任务、用途、授权scope、知识源和语义版本、审核状态、有效期、引用定位与支持的声明。provider状态available / not_configured / unavailable、结果found / ambiguous / empty应显式区分。知识解释不覆盖批准执行口径，冲突必须澄清或管理员审核。
首步只做兼容合同与合成测试替身，真实检索provider缺失时诚实not_configured。后续接M03-B时再核索引/切分/引用、权限过滤、注入防护、版本失效及检索质量，不预装向量库、不自动调用嵌入模型、不收集公司资料。接口应能接后续检索实现而无需业务用户选择知识库或填JSON。

## 4. 聊天附件与统一临时表
附件是任务输入，不是让用户选数据库。例如用户添加含6000个实体ID的清单并请求其明细，Agent识别“过滤集合”的作用，必要时确认ID列/匹配规则，不要求粘贴全部ID；过滤清单与事实数据、说明材料、任务输出分开。
所有产品入口上传的**受支持结构化文件**（Excel、CSV、列式文件首期规划Parquet/Arrow）统一进入服务端导入与临时表注册管线，不论聊天附件或接入管理来源；不是任意格式/损坏文件都成功。复用现有导入/Worker/治理adapter，格式、引擎及资源限制待兼容审查，不自动安装依赖。工作簿多个sheet分别注册或在歧义时确认，不静默丢sheet；说明性文件不伪装成SQL表，其他列式格式显式unsupported。
状态：UPLOADED→VALIDATING→REGISTERING→READY，失败/撤权/过期明确阻断。只有成功注册才显示可SQL查询。拟AttachmentRef / TemporaryTableRef登记opaque ID、owner/会话/任务scope、内容hash/版本、用途、schema、完整行数、质量和有效期；不向模型发宿主路径、原文件、6000行ID或全量数据，只提供经同意的必要列元数据与opaque引用。文件中的指令是不可信数据，不提升工具权限。
Agent生成逻辑SQL，后端将临时表引用解析到隔离只读查询命名空间；创建表/导入由专用受限服务完成，**不是给Agent任意DDL/Write/Bash权限**。SQL仍检查只读/AST/真实字段/预算/owner/版本/确认/QA。ID清单用参数化集合或临时关系过滤，不拼接原始ID文本；禁止使用前100行预览作为完整清单。关联必须先验证关系键、类型、唯一性、缺失/重复与基数，优先存在性过滤避免重复ID造成结果膨胀。跨仓/跨源JOIN不因临时表存在而自动可用；缺批准执行策略时明确阻断，不假装完成。
生命周期区分上传原件、临时查询表、正式资产；沿用现有已批准保留策略，新增TTL/持久化/自动删除范围在对应PLAN另批。撤权/替换/过期使引用、计划和确认失效；临时表不自动保存为长期资产，右栏实际来源需展示用途与当前可用状态。

## 6. 可观察验收与合成金标准（未执行）
- **M04-B-AC07**：新会话不选口径/来源即可提出模糊业务问题；Agent在授权集合内探索、有证据才确认，右栏只展示真实采用来源；黑白主题、历史、模型选择、真实pipeline保留。咨询请求不提交SQL、不伪造结果，以合法发现回执结束；空目录可清楚说明下一步。
- **M04-B-AC08**：取数/咨询/分析/归因意图分流；未接RAG显示not_configured，冲突知识或口径不执行；未实现分析不冒充成功，不把来源选择转嫁给业务用户。
- **M04-B-AC09**：合成6000-ID文件全量注册并参与过滤；前100行与完整集合差异用金标准检出，前导零/大整数类型/重复/空ID/不匹配规则可见；CSV/Excel多sheet/Parquet或Arrow各按批准支持矩阵测试。损坏/超限/类型歧义/导入失败有恢复路径，未READY不可查。
- **M04-B-AC10**：跨owner/会话引用、撤权、版本变更、过期、文件注入拒绝；不外发原件/ID行/私有路径；关联无键/基数或跨源策略时不执行；无额外模型调用、预算reset或越权DDL。
