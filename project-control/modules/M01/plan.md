## 技术方案与替代项

### A 推荐 Web优先及独立Python后端

- 前端 React + TypeScript + Vite；本产品是登录后的交互工作台，首期不需要SEO或服务端渲染，因此不先引入Next.js。路由按工作台需要配置，保持未来组件SDK可拆分。
- 后端 Python 3.12 + FastAPI + Pydantic v2，REST/OpenAPI合同；与数据及建模生态一致。
- 控制面 PostgreSQL为目标数据库；M01先定义仓储接口及仅开发/测试用内存实现，不把内存存储宣传成持久化。真实持久化与任务执行在M05完成并测试。若用户要求M01即完整数据库，先调整本模块范围。
- 数据载体 Arrow/Parquet，受保护存储接口支持未来S3兼容实现；M01只冻结最小资产Schema，不提前实现上传下载和所有对象存储。
- 测试 pytest/httpx用于后端，Vitest及适用React测试工具用于前端，Playwright用于浏览器流程；只引入当前必要依赖。编排先确定性状态机，不引入重型Agent框架。
- 开发环境 Python项目虚拟环境、前端项目依赖、明确启动脚本及锁文件。Windows本地可开发，后端及Worker目标Linux部署；本模块不要求Docker存在，不自动安装系统数据库或容器平台。

许可初步情况：React、Vite、FastAPI、Pydantic、pytest及Vitest通常为MIT；TypeScript、Arrow及Playwright为Apache-2.0；PostgreSQL为PostgreSQL License。以上不是已完成供应链审计，实际锁定版本、传递依赖和许可证在实施时核对。所用库版本不得凭空写成最新。

运行时盘点：本机可用的指定Python为3.12.14，Node为24.22.1，Pydantic为2.14.1；FastAPI、pytest、httpx尚未确认可用。docker/psql在当前PATH未发现，不代表整机绝对未安装。产品开发使用项目依赖，不修改当前桌面应用托管运行时。网络下载、端口及服务运行遵守环境审批。

### B 替代 Next.js及Python后端

适合未来同时需要公开内容站、SSR或更重的服务端前端框架；当前工作台收益有限，会增加两套服务端边界和部署学习成本。仍可保留Python，后续需要时迁移，不因已有策划提到Next.js而默认锁死。

### C 替代 桌面优先

Tauri或Electron封装React页面并连接Python服务。适合必须有安装包、深度本地文件/离线能力的客户，但新增安装、升级、签名与平台验证；企业SaaS嵌入还需Web版本。首期不推荐。

当前选择A同时确认Web优先与本模块技术方案；不是批准全部未来依赖、真实查询或公开上线。

## M01 输入输出合同

- QuerySpec：明确指标引用或明确查询目标、时间范围、时区、维度及过滤；用户输入不得写tenant_id、principal或policy_context，后端附加可信执行上下文。是否满足完整业务槽位由M03/M04处理。
- Task：稳定task_id、状态、时间、trace_id、当前阶段及规范错误；状态转移合法，未接入执行器的请求不能返回伪造SUCCEEDED或结果。
- DatasetAsset：asset_id/version/schema_version、字段类型、粒度、单位、来源、质量、权限引用与受保护data_ref。M01定义最小合同，不生成虚假业务资产。
- ConnectorCapability：元数据/异步/取消/成本等能力与unknown显式状态，M02沿用。
- AuthContext：来自服务器身份解析器的主体、租户和授权；生产无有效认证配置默认拒绝。开发身份仅显式开发模式启用、仅本地监听，网页显示提示；不信任X-Tenant-ID等客户端自报身份。
- Error：code、safe_message、trace_id；不给前端完整异常、密钥或敏感字面量。

拟定API：GET /health/live、GET /api/v1/session、GET /api/v1/capabilities、任务合同的创建/读取端点及JSON Schema导出。未接入模块返回明确unsupported/not_configured或非成功的待处理状态；具体状态与响应码在实现测试中固定，不用空成功掩盖未实现。

## 风险及回滚

开发身份和内存仓储不能进生产；部署配置fail-closed并有显式警告。前端显示的主体/租户不作为授权来源。核心Schema变更将影响后续模块，发布版本并进行兼容检查。Node24与实际依赖兼容在安装时验证。若需要SSR或桌面优先，先回PLAN重新选择，不静默换栈。

本模块不修改生产数据或已有数据库；工作区新增代码隔离。回滚停本地服务、恢复受影响源码及配置，不递归删已有项目文件。交付需要实际测试证据、self_review审计及用户验收；验收前不切换M02活动状态。
