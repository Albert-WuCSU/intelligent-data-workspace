## Product constraints

This is an AI product-manager portfolio project delivered as a real Web application. Preserve the accepted business-user conversation workspace, prominent black/white theme selection, history, top actual-status pipeline and structured result cards. SQL/Schema verification belongs in developer tools, not the business default task. Plan and audit modules around roles, tasks, progressive disclosure, understandable evidence and actionable failure states, not a list of technical features.

The query agent must access actual authorized warehouse metadata and SQL execution through governed MCP/adapters. Data-asset contracts are downstream handoff, not a substitute for warehouse access. Never manufacture business numbers, downloads, successful execution, user research or causal conclusions. Local development conversation history and memory tasks are not production persistence or authentication.
